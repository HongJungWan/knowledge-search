## 3. 갭 트리아지

| ID | 갭 | 판정 | 근거 |
|---|---|---|---|
| KS-1 | `domain`/`codeValues`/`contentHash` raw String (VO 미적용) | **보류 — 유지** | CLAUDE.md "query-target VO 미도입". QueryDSL where/join/index 타깃. `@ValueObject` 미부착 → ArchUnit 위반 아님. |
| KS-2 | 도메인 이벤트 미소비 | **보류 — 유지** | `@DomainEvent` 실제 사용 없음(인벤토리 §2 확인). dead code 회피, 올바른 결정. |
| KS-3 | `BaseEntity.softDelete()`가 `Instant.now()` 호출 | **보류 — 유지** | `global/common` 소속(도메인 레이어 아님). 훅 `.now()` 룰·ArchUnit은 `domain` 글롭 한정 → 미플래그. 의도적 스코핑. |
| KS-4 | Redshift `search`에 임베딩 arm 없음 (RRF는 Postgres만) | **개선(위반 아님) → R1** | 포트가 이미 5-arg `default`로 keyword-only graceful degrade 모델링. 비대칭은 *역량 격차*이지 DDD 위반 아님. R1로 명시·관측가능화. |
| KS-5 | `list_schema`가 하드코딩 카탈로그 반환 | **개선 + 잠재 ACL 갭 → R2** | 물리 스키마 SSOT는 metadata-ontology(`SchemaCatalog`). `MetadataResolvePort` ACL 패턴으로 소싱. |
| #1 (로드맵) | Anemic model 의심 | **이미 충족** | 인벤토리 §2: 두 AR 모두 팩토리 + 행위 메서드 보유. `anemicModel: block` 통과. 조치 불요. |

**순수 개선 작업**: R1(KS-4, 저위험), R2(KS-5, 중위험). 그 외는 "그대로 두기"가 정답.
